# AINCRAFT

AINCRAFT is an independent, Aincrad-inspired fantasy RPG project built on Minecraft Java Edition, with a custom Windows launcher. The project is currently in development.

## The project

AINCRAFT brings a modded Minecraft experience and multiplayer world together behind one launcher. The current development pack targets Minecraft Java Edition 1.21.4 with Fabric.

## The launcher

The launcher installs and verifies the required game files, manages its own game directory, and is designed to connect players to AINCRAFT directly. Players need a Microsoft account with access to Minecraft Java Edition.

Microsoft sign-in takes place on Microsoft’s own website using device-code authentication. The launcher does not ask for Microsoft passwords. Local session data is encrypted using Windows account storage. Minecraft Services application approval and end-to-end account testing are still in progress.

## Development status

This public repository contains a project overview only. Source code, game files, launcher executables, and public releases are not published here at this stage. There is no public download or announced release date yet.

AINCRAFT is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft.
