AINCRAFT is a Minecraft Java RPG project I'm working on, inspired by Sword Art Online and Aincrad. It includes the game world, a modded client, and a custom Windows launcher. The project is still in development.

![Aincrad Minecraft screenshot used in AINCRAFT](aincrad.png)

## The project

I'm building AINCRAFT around an Aincrad-inspired setting in Minecraft. The world and game content are being worked on alongside the launcher, which handles the files needed to run the project.

The screenshot above is the Minecraft scene currently used in the launcher. I'll add more of the project here as development progresses.

## The launcher

The launcher is a Windows desktop app built specifically for AINCRAFT. It installs the game files, checks for missing or incomplete downloads, and prepares the Java runtime. The game needs to be fully installed before Play becomes available.

The current development build uses Minecraft Java 1.21.4, Fabric 0.20.0, and Java 21 on Windows x64. AINCRAFT has its own game folder, with a file verification and repair option. Player settings and saves are kept when verifying the installation.

The interface uses the full AINCRAFT logo, Minecraft pixel fonts, and the Aincrad screenshot shown above.

## Development

I'm testing the launcher locally while continuing work on the game. This repository currently contains the project overview and branding images. Source code, game files, and launcher builds are still private, and there are no public downloads or release dates yet.
